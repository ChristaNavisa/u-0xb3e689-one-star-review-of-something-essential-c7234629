A program that writes one deadpan one-star review, 160 characters or fewer,
of an everyday essential to `/output/entry.txt`.

Entry for the [One-Star Review of Something Essential](https://make.fun/c/u-0xb3e689-one-star-review-of-something-essential-c7234629)
bounty on make.fun.

## Run

```sh
node main.ts
```

Writes the review to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when the harness sets it).
